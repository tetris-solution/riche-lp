減量には、食事から摂るエネルギーと、運動や日常生活で使うエネルギーのバランスが関わります。食事と活動量を見直し、記録で取り組みを確かめる。それが、このプログラムの基本です。

01 / FOOD METHOD

忙しい人のために、
食事をシンプルに。

糖質・脂質・たんぱく質をバランスよく摂り、活動量に合わせて食事量を調整する。それが基本です。

でも、仕事や家事で忙しい毎日。朝・昼・晩すべてを計算し、栄養バランスの整った献立を用意し続けるのは簡単ではありません。

朝はパン、昼は麺や丼、夜は総菜や外食。選び方や量によっては、糖質と脂質が重なり、摂取エネルギーが増えることがあります。

RICHEの食事ルール

まず、糖質量を決める。

糖質を悪者にするためではありません。何を選び、何を控えるかを判断しやすくするためです。

我慢を増やすためではなく、
毎日の食事の「迷い」を減らす。

毎食の細かな計算に頼りすぎず、食事全体の量と栄養バランスも見ながら進めます。

糖質制限で目指す5つのこと

  1. 高糖質・高脂質の食品を減らす
  2. 摂取エネルギーを管理しやすくする
  3. 肉・魚・卵・大豆製品などからたんぱく質を確保する
  4. 空腹による間食や食べ過ぎを抑えることを目指す
  5. 自分に合った糖質量を理解する

ケトジェニックダイエット（糖質を強く制限し、ケトーシスを目指す食事法）について、減量時の空腹感の増加を抑える可能性が報告されています。通常の糖質制限と同じ条件ではなく、週の実践日数だけでケトーシスや同じ効果を保証するものではありません。効果や感じ方には個人差があります。研究を見る［1］

糖質を、一生禁止する
プログラムではありません。

糖質は身体を動かすエネルギー源のひとつ。RICHEは、糖質をずっと食べない生活を目的にしていません。

01 / 短期プログラム

分かりやすいルールで糖質を制限し、食事の選び方を整理する。

02 / 中長期プログラム

体調や経過を見ながら少しずつ糖質を取り入れ、自分に合った量を覚える。

糖質を食べない生活ではなく、
糖質に振り回されない生活へ。

具体的な糖質量と進め方は、体調・活動量に合わせて相談します。治療中・服薬中の方、妊娠・授乳中の方は、開始前に医師へご相談ください。

02 / TRAINING METHOD

落としたいのは、
筋肉ではなく体脂肪。

食事だけを極端に減らすと、体脂肪と一緒に筋肉も減ってしまう可能性があります。RICHEでは、筋力トレーニングとサーキットトレーニングを組み合わせ、筋肉を守りながら体脂肪を減らし、引き締まった身体を目指します。

01 / 筋力トレーニング

筋肉に刺激を。
見た目にも変化を。

スクワット、プレス、ロウなど、全身の大きな筋肉を使う種目を中心に。運動経験や体力に合わせて、重さと回数を調整します。

  1. 減量中の筋肉をできるだけ維持する
  2. 筋力の向上を目指す
  3. 姿勢や身体の使い方を整える
  4. 引き締まった見た目を目指す

過体重・肥満の成人を対象とした研究の統合では、食事による減量に筋力トレーニングを加えると、食事だけの場合より除脂肪量（脂肪以外の組織）を維持しやすい結果が報告されています。全員の筋肉増加を意味するものではありません。研究を見る［2］

02 / サーキットトレーニング

全身を動かす。
続けられる体力を。

複数の運動を短い休憩でつなぎ、大きな筋肉を繰り返し使います。筋力と心肺機能の両方へ刺激を与え、運動を継続する力も育てます。

  1. 短時間で全身を動かす
  2. 心拍数を高め、運動中のエネルギー消費を促す
  3. 心肺機能の向上を目指す
  4. 運動後の回復に伴う酸素消費にも着目する

運動後、身体が回復する過程で、安静時より酸素消費が高くなることがあります。これがEPOC（Excess Post-exercise Oxygen Consumption／運動後過剰酸素消費量）。「アフターバーン」とも呼ばれます。

高強度インターバル運動や、休憩の短い筋力トレーニングでは、運動後の酸素消費が大きくなる傾向が報告されています。ただし、大きさ・持続時間は運動条件や個人で異なり、これだけで大幅な減量ができるという意味ではありません。強度は体力に合わせて調整します。研究を見る［3］・研究を見る［4］

紹介した研究は一般的な食事・運動の知見です。RICHEのプログラムによる−6kg達成を証明・保証するものではありません。

BEFORE YOU START

気になる質問、
全部答えます。

食事も、運動も、お金のことも。申し込む前に、気になることを確認してください。

本当に−6kg痩せられますか？

−6kgは全コース共通の目標で、結果を保証する数字ではありません。スタート時の体格・健康状態・生活習慣を確認し、減量が適切かも含めて目標と期間を相談します。

厳しい食事制限や、毎日同じ食事が必要？

食事管理をシンプルにするため、糖質量を決めるルールを取り入れています。糖質を一生禁止するものではありません。管理栄養士監修の方針をもとに、体調や活動量に合わせて内容を相談します。避けたい食材、外食の頻度、自炊が難しいことも相談時にお伝えください。

運動が苦手。スパルタコースは怖くない？

「スパルタ」は2か月・食事ルール週6日の集中コースの名前です。運動経験や体力、痛みの有無を体験時に共有し、取り組む内容を相談します。

忙しくて、週に何度も通えません。

週6日・4日・2日は、食事ルールに取り組む日数です。来店回数ではありません。トレーニングは2か月16回・4か月24回・6か月30回です。1回の時間・予約の空き状況を確認してから、生活に合うか判断してください。

食べすぎた日や、体重が落ちない時は？

食事や運動の記録と体重の推移を、一緒に振り返るためのアプリです。うまくいかなかった日も記録を残し、何が難しかったのか、次に何を変えるかを相談します。

終わったあと、リバウンドしませんか？

リバウンドしないという保証はありません。コース中の記録から、自分で続けられる食べ方や運動のペースを見つけることも目指します。終了後のサポートの有無・範囲は、申し込み前にご確認ください。

管理栄養士が毎日直接返信してくれますか？

本プログラムは管理栄養士監修の食事サポートです。監修と、管理栄養士による個別相談・直接返信は異なります。アプリの返信担当、対応時間、個別相談の有無は体験時にご確認ください。

料金や追加費用、途中解約が気になります。

コース料金は2か月16回198,000円、4か月24回264,000円、6か月30回330,000円です。入会金・アプリ利用料などの追加費用の有無、支払い方法、キャンセル・途中解約・返金条件は、申し込み前にご確認ください。公式LINEから希望するコースとあわせてお問い合わせいただけます。
